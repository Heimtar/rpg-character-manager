Менеджер и генератор RPG-персонажей (Junior+)

Что нужно было сделать (Техническое задание):

Создать веб-приложение для настольных ролевых игр (типа D&D), позволяющее гибко создавать, настраивать и сохранять карточки героев в личную коллекцию. Проект должен был имитировать реальные бизнес-задачи: работу со сложными вложенными структурами данных, валидацию форм, клиентское хранение данных и продвинутый пользовательский опыт (UX/A11y).

Какие инструменты и технологии использовали:

-React (v18+) — компонентный подход, управление реактивным состоянием.
-Vite — современный, сверхбыстрый сборщик проекта (замена устаревшему Create React App).
-Node.js (v24) — серверное окружение для запуска инструментов сборки.
-JavaScript (ES6+) — базовый язык логики приложения (методы массивов, деструктуризация, асинхронность).
-HTML5 / CSS3 (Grid + Flexbox) — создание адаптивной двухколоночной сетки и интерфейса в стиле Dark Fantasy.
-Git / GitHub — контроль версий по международному стандарту Conventional Commits.

Что было сделано (Ключевой функционал проекта)

-Управляемая форма создания: Поля ввода имени, интерактивные выпадающие списки выбора Расы и Класса.
-Умный пул характеристик: Система распределения 20 бонусных очков (Сила, Ловкость, Интеллект, Мудрость) с защитой от ухода очков в минус или ниже базового порога (10 очков).
-Динамические расовые бонусы: Реализована игровая логика математики на лету (например, Орк получает +3 к Силе и -1 к Интеллекту). 
-Бонусы наглядно подсвечиваются цветом в интерфейсе и честно учитываются при сохранении.
-Продвинутый UX и Валидация: Строка статуса формы динамически меняет цвет и текст (Красный: «Заполните имя и распределите очки» / Зеленый: «Персонаж готов к созданию»). 
-Системные алерты заменены на кастомное модальное окно с анимацией появления.
-Полноценная Библиотека героев: Карточки сохраненных персонажей выводятся в интерактивную сетку с возможностью мгновенного удаления через метод .filter().
-Клиентская база данных (localStorage): Интеграция сохранения данных в браузер через хук useEffect и парсинг строк JSON. Персонажи не исчезают при обновлении страницы (F5).
-Живой поиск и Фильтрация: Реализован поиск по имени в реальном времени (нечувствительный к регистру букв), совмещенный с фильтрами по классам и расам внутри библиотеки.
-Доступность (Accessibility / A11y): Полная поддержка управления сайтом без мыши. С помощью клавиш Tab, Enter и Space можно пройти всю форму и прокачать статы. Использовано свойство :focus-visible для предотвращения «залипания» рамок после клика мышью.
